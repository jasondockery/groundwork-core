# Skills

This directory contains the local [docs-alignment](docs-alignment/SKILL.md)
procedure and imported engineering skill references. Groundwork Core owns shared
operational Markdown, skills specific to that guidance, and project scaffolds.
Installer procedures stay in their environment repositories.

For active shared engineering procedures, use the canonical
[Compass skills](https://github.com/jasondockery/compass/tree/main/skills).
The other copied skill files here are reference material from the initial split,
not independently maintained procedures or a complete executable projection.
Some require Compass policies, registry, receipt, or checkers that this repo does
not ship. Reading a copy does not establish adoption or permit bypassing those
prerequisites. Do not install this directory as a skill bundle; follow Compass's
distribution contract if a consumer needs a complete offline projection.
